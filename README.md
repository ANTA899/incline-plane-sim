# 巧用斜面 · 虚拟仿真实验

小学科学（教科版五年级上册）《巧用斜面》一课的交互式虚拟实验。单个 HTML 文件，浏览器直接打开即可运行，无需安装、无需构建。

## 实验内容

实验按四个任务递进，前一个任务的结论是后一个任务的起点：

| 任务 | 名称 | 要点 |
| --- | --- | --- |
| 任务 1 | 直提与斜拉的较量 | 先猜后测。用同一块 60 cm 木板，对比「直接提起货物」和「沿斜面拉上去」所需的力 |
| 任务 2 | 搭建「缓」与「陡」 | 改变木板倾角，观察坡度对用力大小的影响 |
| 任务 3 | 寻找最省力的斜面 | 在多个木板长度之间横向比较，找出最省力的一档 |
| 任务 4 | 挑战木板组合 | 拼接多块木板模拟盘山公路，理解「省力但费距离」 |

每个任务有独立的实验记录表，互不干扰；清空记录前会二次确认。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `bevel_test.html` | 主程序，包含完整的四个任务（约 111 KB，单文件自包含） |
| `base.html` | 「启智」通用界面布局模板，提供现象区 / 实验条件 / 界面记录 / 实验指南四块骨架 |
| `example.html` | 参考样例：食物保鲜实验室（怎样减慢食物变质的速度） |
| `audit.js` | 与本实验无关：PhET 仿真覆盖率审计脚本，依赖 `puppeteer-core`，需 Node.js 环境 |

## 本地打开

双击 `bevel_test.html`，或拖进浏览器。无任何外部依赖：没有 CDN 链接、没有 npm 包、没有构建步骤，`file://` 协议下直接可用。

## 技术说明

- 原生 HTML / CSS / JavaScript，不依赖任何框架
- 场景与图表用 SVG 绘制，非 canvas
- 物理量（拉力、高度、坡度、距离）用简化的定性模型，服务于小学阶段的「省力」概念建立，不做精确的牛顿力学计算
- 交互按钮：试推、直提、斜拉、重置；支持多轮试推并累计记录

## 已知限制

- 未做移动端适配，建议在宽度 1024 px 以上的窗口使用
- 记录数据只存在页面内存中，刷新即丢失，不落盘
